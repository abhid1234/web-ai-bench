§8. The MediaPipe wrinkle (positioning reminder)

Google's own MediaPipe project has 34,800 stars and active 2026 releases. @mediapipe/tasks-genai at ~7,477 weekly downloads — 9× @litertjs/core.

The honest distinction: MediaPipe = pre-built task pipelines (you bring an image, MediaPipe gives you bounding boxes from curated models). LiteRT-LM = Gemma LLM inference in-browser via MediaPipe. @litertjs/core = general-purpose .tflite runtime (you bring your .tflite, runtime gives you tensors, works for any model type).

Every pitch artifact must name this distinction. The Web Models collection on litert-community currently reinforces the wrong perception — 16 models, all Gemma/LiteRT-LM, 0 @litertjs/core.
